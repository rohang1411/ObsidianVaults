## 1. Prerequisites

* Python 3.8+
* NVIDIA GPU with CUDA (for running the `trainer.py`)
* An [[2. Apache Kafka]] cluster (a running instance). You can download Kafka [Apache Kafka](https://kafka.apache.org/downloads) or use a cloud-based service.

2.  **Create a Virtual Environment (Recommended):**
    ```bash
    python -m venv venv
    ```

3.  **Install Dependencies:**
    The project contains a `requirements.txt` file. Install all required libraries using pip:
    ```bash
    pip install -r requirements.txt
    ```
    *(This would install `torch`, `transformers`, `peft`, `kafka-python`, `flask`, `gunicorn`, etc.)*

## 3. Configuration

1.  **Set up Kafka:**
    * Ensure your Kafka server is running.
    * Create the two required topics (as specified in the architecture):
        ```bash
        # (These commands are examples)
        kafka-topics.sh --create --topic training_data --bootstrap-server localhost:9092
        kafka-topics.sh --create --topic lora_weights --bootstrap-server localhost:9092
        ```

2.  **Edit `config.yaml`:**
    * Open the `config.yaml` file.
    * Update the `kafka` section with your bootstrap server address (e.g., `localhost:9092`).
    * Verify the `model_name` points to the correct base model (e.g., `Qwen/Qwen2.5-1.5B-Instruct`).
    * Configure any [[3. LoRA (Low-Rank Adaptation)|LoRA]] parameters as needed.

## 4. Running the Framework

The InfiniTune framework requires **three separate terminals** to run its decoupled services.

### Terminal 1: Run the Inference Server

This service starts the [[1. Flask]] API and begins listening for weight updates.
```bash
python inference_api.py
```
*(For a production setup, you would use Gunicorn as specified in the report)*
```bash
gunicorn --workers 1 --threads 8 --timeout 0 inference_api:app
```

### Terminal 2: Run the QLORA Trainer

This service connects to the data stream and begins the [[2. Online Learning (ML)|online fine-tuning]] process. **This requires the GPU.**
```bash
python trainer.py
```

### Terminal 3: Run the Data Generator

This service starts the data stream. **Run this last.**
```bash
python producer.py
```

Once all three services are running, the system is live. You can now send prompts to the Flask API endpoint, and the model's knowledge will be updated in the background every ~60 seconds.
