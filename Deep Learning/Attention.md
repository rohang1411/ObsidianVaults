
[[Recurrent Neural Networks | RNN]] - Started adding feedback loop (some sort of context/memory)
[[Long Short Term Memory Networks (LSTM) | LSTM]] - Increased context by adding long term memory
[[Encoder Decoder Models| Encoder Decoder Architecture]] - Utilized short term and long term memory but condensed the entire input into context vector before giving it to Decoder. Hence, decoder didn't have all the context
[[Attention]] - Adds context directly to the decoder cells from the input/encoder cells
